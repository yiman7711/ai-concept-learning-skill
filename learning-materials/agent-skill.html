⏱ 60 秒核心点

Agent Skill（智能体技能） = 一种打包"方法 + 知识"的能力文件，让 Agent 在遇到相关任务时自动按需加载你的专长，而不用你每次重新解释。它本质是"把做过的事，变成可复用、稳定的能力"。
① 它长什么样一个目录，核心是 SKILL.md：顶部 YAML 写 name/description（用于"何时触发"匹配），正文写分步操作指引；可附带脚本 scripts/ 与参考文件。
② 关键机制：渐进式披露平时只占约 100 token 的元数据 → 任务命中才读完整 SKILL.md（<5K token）→ 用到才读脚本/资料。→ 不挤占上下文。
③ 和普通 Prompt 的区别Prompt 是一次性、随会话消失；Skill 是独立文件、跨会话复用、可给模型"装专长"。
组成作用一句话
name/description被模型扫描、决定何时触发Skill 的"门牌"
SKILL.md 正文告诉模型"这类任务怎么做"可复用的"交接手册"
脚本 / 资源执行确定性操作 / 查资料只把结果带回上下文
一句话记忆：触发看 description，干活看 SKILL.md，省内存靠按需加载。
