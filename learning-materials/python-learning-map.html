知识点 ①：变量与基本类型（10 分钟）

变量就是给数据起名字。四种常用类型，用新闻场景理解最快：

类型长什么样新闻场景后面 AI 课的用途
str 文本"暴雨蓝色预警"标题、正文、作者名文本预处理、拼 Prompt
int 整数860稿件字数、阅读量样本数、类别编号
float 小数3.14同比增幅、客单价准确率、损失值

最容易踩的坑："1200"（带引号）是文本，1200（不带引号）是数字。 从 CSV、Excel、网页拿下来的数字几乎都是文本，不能直接计算，必须先 int() 转换。这个坑你一定会遇到。

知识点 ②：字符串六件套（16 分钟，本课核心）

新闻的本质是文本，字符串操作是这 4 次课里性价比最高的知识。只要六招：

title = "  AI 大模型加速落地：新闻业迎来效率革命  "

# ① len —— 数长度（标点、空格都算）
print(len(title))                  # 23

# ② strip —— 去掉首尾空格（抓数据后必备，不然后续匹配全错）
title = title.strip()

# ③ in —— 判断有没有某个词
print("AI" in title)                 # True

# ④ replace —— 替换
print(title.replace("大模型", "AI 模型"))

# ⑤ split / join —— 切分与拼接（处理 CSV、日期、地址全靠它）
print(title.split("："))              # ['AI 大模型加速落地', '新闻业迎来效率革命']

# ⑥ f-string —— 把变量嵌进句子（最常用，务必记牢）
print(f"这条标题共 {len(title)} 个字")

顺带认识两个转换函数：int("860") 文本变整数、str(860) 整数变文本。 input() 拿到的输入永远是文本，需要数字时必须转。

动手小作品：稿件字数统计器

要求：向用户要一段稿件文字，输出"总字符数 / 去掉空格后的字数 / 是否超过 800 字上限"。

通关标准：脚本能跑通，且粘贴一段真实中文稿件进去，结果正确。 如果中文乱码或报 UnicodeEncodeError，先解决再下课。

这节课常见的 3 个坑

  • 中文引号 " " 混进代码——Python 只认英文半角引号。
  • 缩进混用 Tab 和空格 → IndentationError。统一用 4 个空格。
  • 忘了 strip()，导致 "AI" in title 判断失败——空格和换行是最隐蔽的敌人。

核心问题

"一条数据我能手动处理，一百条怎么办？Python 靠什么把一堆数据装起来并批量操作？"

这一课是整个预备阶段最重要的一课——AI 课上的数据集、模型输出、JSON 返回，本质全是"列表套字典"。

知识点 ①：列表 list（11 分钟）

列表就是有顺序的一串东西。记住"增删改查 + 遍历"两条线：

titles = ["AI 大模型落地新闻业", "暴雨蓝色预警发布",
          "AI 生成内容标识新规出台", "本地马拉松赛今日开跑"]

print(titles[0])          # 取第一个（注意：从 0 开始数！）
print(titles[-1])         # 取最后一个
print(len(titles))       # 一共几条

titles.append("新的一条标题")      # 末尾添加
titles.sort(key=len)             # 按长度排序（key=len 是关键技巧）

for t in titles:                # 遍历：对每一条都做一遍
    print(t)

知识点 ②：字典 dict（10 分钟）

字典是带标签的数据：每个值都有一个名字（键）。一条新闻天然就是字典。

article = {
    "标题": "AI 大模型落地新闻业",
    "作者": "张三",
    "字数": 860,
    "已发布": True,
}

print(article["标题"])          # 用键取值
article["字数"] = 900         # 改值

# 关键组合：列表里装字典 ＝ 一张表格 ＝ 数据集的基本形态
articles = [article,
            {"标题": "暴雨蓝色预警发布", "作者": "李四",
             "字数": 520, "已发布": False}]
print(articles[0]["作者"])      # 张三
这句话请务必记住："列表套字典 = 表格"。 AI 课上你会不断遇到这个结构：数据集是一堆记录、模型的 JSON 返回是嵌套字典。 理解它，后面会轻松一大截。

知识点 ③：条件与循环（10 分钟）

for a in articles:
    if a["字数"] > 800:                      # 条件成立就走下面
        print(f"【长稿】{a['标题']}")
    elif a["已发布"] is False:              # 否则如果
        print(f"【待发】{a['标题']}")
    else:                                    # 都不满足
        print(f"【常规】{a['标题']}")

循环只要记两种：for（对一批东西逐个处理，用得最多）和 while（条件成立就一直转，用得少，认识即可）。 range(5) 生成一串数字，用于"重复 5 次"。

动手小作品：标题筛选与排序器

要求：给 10 条标题，筛出含 "AI" 的，按字数从长到短排序，按 序号. 标题（N 字） 格式输出。

进阶（做得出就做）：把不含"AI"的挑出来放另一个列表，统计两个列表各有几条。

通关标准：不看答案，自己写出 for + if + sort 的组合， 并理解 sort(key=len) 里为什么写 len 而不是 len()。

这节课常见的坑

  • titles[0] 才是第一个——从 0 开始数是 Python 的约定。
  • for 后忘了冒号，或内部代码没缩进 → SyntaxError。
  • 字典取不存在的键 → KeyError。抓来的数据字段名常和你猜的不一样，先 print 看清楚。

知识点 ①：函数 def（9 分钟）

函数就是给一段代码起名字，以后随叫随到。判断标准很简单：同一段逻辑你要是打算写第二遍，就该包成函数。

def count_chars(text):
    """统计去掉空格后的字数"""
    return len(text.replace(" ", ""))

print(count_chars("AI 大模型 落地"))     # 7
print(count_chars("暴雨蓝色预警发布"))        # 8

三个要素：参数（进来什么）、return（出去什么）、函数名（怎么叫它）。 return 和 print 完全不同——print 只是显示，return 才把结果交出去给别人继续用。这是新手最容易糊涂的地方。

知识点 ②：文件读写（12 分钟）

记住这套固定写法，encoding="utf-8" 一个字母都不能漏——Windows 下漏了必然中文乱码或报错：

# 读：整个文件读成一个长字符串
with open("news.txt", "r", encoding="utf-8") as f:
    text = f.read()

# 读：按行读（处理大文件、逐行分析时用）
with open("news.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

# 写：把结果存成文件
with open("result.txt", "w", encoding="utf-8") as f:
    f.write("处理完成\n")
路径的坑：Windows 路径 C:\Users\zuliy\news.txt 里的 \n 会被当成换行符。 要么加 r：r"C:\Users\zuliy\news.txt"，要么统一用正斜杠 "C:/Users/zuliy/news.txt"。 建议：脚本和数据文件放同一个文件夹，直接用文件名，最省事。

知识点 ③：第三方库与 pandas（14 分钟，含出图）

先理解"装库"这件事：pip 是 Python 的应用商店，库是别人写好的工具箱。 这一招是后面 AI 课的生命线——numpy、matplotlib、scikit-learn、PyTorch，全部靠它装。

# 在命令行里执行（不是写在 .py 文件里！）
# pip install pandas matplotlib

# 写在 .py 文件里
import pandas as pd

df = pd.read_csv("news.csv")         # 读成一张表，df 就是"数据框"
print(df.head())                   # 看前 5 行（第一步永远是先看清数据长什么样）
print(df.shape)                    # (行数, 列数)

counted = df["分类"].value_counts()    # 按"分类"列统计各类几条
print(counted)

counted.plot(kind="bar", title="各类新闻数量")   # 直接出柱状图
import matplotlib.pyplot as plt
plt.show()

pandas 只要掌握五个动作，就能做多数新闻数据活： read_csv（读）、head（看）、条件筛选 df[df["列"] > 值]、value_counts／groupby（统计）、plot（画）。

中文图表变方块的解决办法：matplotlib 默认字体不带中文，加两行即可： plt.rcParams["font.sans-serif"] = ["Microsoft YaHei"]、 plt.rcParams["axes.unicode_minus"] = False。
如果 AI 课一上来就用 numpy：把这一课的演示从 pandas 换成 import numpy as np 即可， 套路完全一样（pip 装 → import → 查文档 → 用）。不要为此提前单独学 numpy。

动手小作品：一份 CSV 的分类统计图

要求：准备一份新闻数据 CSV（列至少含"标题""分类"），读出后按分类统计数量，生成柱状图。

  • 把 pip install 写进了 .py 文件——它是命令行命令，不是 Python 语句。

核心问题

"AI 能力到底怎么'装进'我的程序里？所谓'调用 API'，在代码层面究竟发生了什么？"

知识点：调用大模型 API 的通用五步法（11 分钟）

无论用哪家平台，套路完全一样。把这五步背下来，你就拿到了 AI 应用开发 90% 的钥匙。

步骤做什么对应前几次课
1. 准备在平台申请 API Key，装好库第 3 次课 pip
2. 保护 Key存进环境变量，绝不写死在代码里第 3 次课 文件/环境
3. 发请求用 requests POST 一个 JSON 过去第 2 次课 字典
4. 收响应resp.json() 拿回一个字典第 2 次课 字典
5. 取结果按路径一层层取值拿到文本第 2 次课 字典 + 第 3 次课 函数
import os, requests

# 第 2 步：Key 从环境变量读，不写死在代码里
api_key = os.environ["MY_API_KEY"]

def ask_ai(prompt):
    """把一句话发给大模型，拿回它的回答（第 3 次课的函数封装）"""
    url = "https://你的平台接口地址/chat/completions"
    headers = {"Authorization": f"Bearer {api_key}",
               "Content-Type": "application/json"}
    data = {"model": "你的模型名",          # 具体名称以平台文档为准
            "messages": [{"role": "user", "content": prompt}]}
    resp = requests.post(url, headers=headers, json=data, timeout=60)
    return resp.json()["choices"][0]["message"]["content"]

# 第 3、4、5 步：发出去、收回来、取出文本
print(ask_ai("用一句话概括：AI 大模型正在改变新闻生产流程"))
说明：上面是通用骨架，真实的 url、model 名称请以你所用平台官方文档为准 （例如 DeepSeek 开放平台文档给出的调用示例与本例结构一致）。不要凭记忆猜接口地址。
两条绝对不能破的规矩： ① API Key 绝不写进代码、绝不提交到 GitHub。用环境变量 + 把 .env 写进 .gitignore。 ② 批量调用前先算钱。先用 1 条跑通，再跑 10 条，估算单次消耗后，才敢跑 1000 条。

动手小作品：标题批量 AI 摘要 + 分类

这就是预备阶段的毕业作品，把前三次课全部串起来：

  1. 准备 titles.txt，每行一条新闻标题（10 条左右）。
  2. 用第 3 次课的文件读写把标题读进来。
  3. 用第 2 次课的 for 循环，逐条调用 ask_ai()，让它输出"一句话摘要 + 所属类别"。
  4. 把结果攒成"列表套字典"，用 pandas 存成 result.csv。
  5. 用 value_counts() 统计各类别数量并画一张柱状图。
通关标准：脚本一键跑完，产出 result.csv 和一张图； 并且你能对着代码逐行解释在干什么——这最后一条才是真正的过关线。
新闻学的额外一课（很重要）：AI 的输出不是事实。批量生成的摘要和分类必须人工抽检， 人名、数字、机构名尤其要核对。把"AI 生成 → 人工核实"当成固定动作，比多学两个库有价值得多。

这是本图最有价值的一节：告诉你这 180 分钟学的每一样东西，在后面的 AI 课上会以什么形式再次出现。 看懂这张表，你就知道哪些必须练熟、哪些可以先放过。
这 4 次课学的后面 AI 理论与应用课上会怎么用到要求
变量与基本类型表示样本数、特征值、准确率、损失值；区分文本与数值是数据预处理的前提练熟
字符串操作文本预处理：清洗、分词前的切分、拼接 Prompt、截断长文本练熟
列表 / 字典数据集的基本容器、模型返回的 JSON 结构、特征与标签的存放方式必须彻底搞懂
条件与循环遍历数据集、批量推理、按条件筛选样本、训练轮次循环练熟
函数把数据预处理、模型评估封装成可复用模块会用即可
文件读写读 CSV / txt 数据集、保存实验结果、导出预测结果练熟
pip 与第三方库numpy、pandas、matplotlib、scikit-learn、PyTorch 全靠它装必须会
调用 API 五步法大模型应用开发的直接入口，可能整节课都建立在这上面必须会
结论：不需要提前补任何额外内容。 上面表里没有任何一项需要你"预学"AI 概念、数学公式或额外库。 剩下的部分（模型原理、算法、评估方法、应用设计）交给课程本身——那才是这 13 次课真正要学的东西。
唯一值得提前知道的态度：AI 课上老师给出的代码大概率比你的长。 不要怕——你已经有能力读懂它了：先看输入输出，再找循环和条件，最后看它在调什么库。这个"拆解顺序"比多背语法有用。

5. 边界：这 180 分钟不学什么

时间是最稀缺的资源。以下内容在这门课的 AI 场景里出现频率极低，这 4 次课一律跳过，以后真用到再补：

  • 面向对象：类、对象、继承、多态
  • 高级语法：装饰器、生成器、迭代器、多线程、异步
  • 算法与数据结构：刷题那套
  • 爬虫进阶：反爬对抗、Selenium、动态渲染、代理池
  • Web 后端框架：Django、Flask
  • 机器学习算法的数学推导：后面的 AI 课会讲，现在不要抢跑
判断依据很朴素：这 4 次课要解决的是"看得懂、改得动"，不是"写得出优雅的 Python"。 上面这些内容，在你当前的课程里大概率一次都用不上。

8. 怎么把这四次课真的上完

节奏安排（推荐 3 周）

时间做什么时长
每周固定 1–2 次上一节课（含 20 分钟动手）45 分钟
当周其余时间3 次微练习，每次改一个小东西3 × 10 分钟
每节课开始前打开上节课的代码跑一遍，看还认不认识5 分钟
AI 内容开始前做完第 6 节的"交棒检查"10 分钟

四条硬规则

  1. 每节课必须看到东西跑出来。只听课不动手，等于没上。
  2. 代码自己敲，不要复制粘贴。打错字再修好，这个过程本身就是学习。
  3. 卡住不超过 15 分钟。超时就把完整报错信息复制给 AI，要求它"解释原因、提示方向，先别直接给答案"。
  4. 每节课的代码存下来。建一个 python-practice 文件夹，按课次命名。这是你唯一的进度凭证。

关于用 AI 学 AI 的做法建议

让 AI 当"随时在的助教"，而不是"代笔"。提问时把现象 + 报错 + 你已试过的办法一起说清楚， 并要求它解释原理而不是直接贴答案。学完一个知识点后，用自己的话向它复述一遍，让它挑错——这个用法效率极高。
