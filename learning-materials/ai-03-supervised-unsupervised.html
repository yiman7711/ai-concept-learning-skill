监督学习与无监督学习 精讲

个人学习卡片 · 由 concept-mastery Skill 生成 · 学习日期 2026-09-17 · 领域：大数据与人工智能

0. 一句话定位

监督学习（Supervised Learning）是每个样本都带一个"标准答案"（标签），模型学着把输入映射到答案；无监督学习（Unsupervised Learning）是没有答案，模型自己去发现数据里的相似性、结构与分组。两者的分界线只有一条：有没有标签——有答案就"对答案学"，没答案就"自己找结构"。

1. 学习目标

  • 我能用一句话说清"标签（label）"到底指什么，并把它与"特征（feature）"区分开，各举一例。
  • 我能判断一个具体任务该叫分类还是回归，并说出判断依据是"输出是类别还是数值"。
  • 我能各说出四种常见的监督学习算法与三种常见的无监督方法，并讲清它们大致用来做什么。
  • 我能解释无监督学习"难以评估"的原因，并说出有真值标签时用哪些指标、没有时用哪些指标。
  • 我能用一两句话说明半监督学习（semi-supervised）与自监督学习（self-supervised）各自绕开了什么现实困难。

2. 核心问题（本资料将正面回答）

  1. "标签"和"特征"经常一起出现，它们到底差在哪？为什么说标签是监督学习的命门？
  2. 同样是做预测，什么情况叫分类、什么情况叫回归？这条线为什么重要？
  3. 一个没有答案的数据集，模型到底能"学"出什么？
  4. 无监督学习没有标准答案，凭什么判断这次分得好不好？
  5. 给数据打标签又贵又慢，半监督和自监督是怎么绕过去的？

3. 结构化解释

3.1 我的理解

我最开始把"无监督学习"理解成"没人管，机器自己乱学"。后来发现完全不是——无监督只是"没有标准答案"，不是"没有人做决定"。簇要分成几类、怎么衡量"像"、数据怎么清洗，仍然由人设定。IBM 那句话我印象很深：无监督算法可以理解为某种程度上的"自我优化"，所以人的精力从"造标签"转移到了"喂什么数据、设什么参数"上。换句话说，监督学习和无监督学习的区别不是"有人 / 没人"，而是"有没有一把外部的尺子可以量对错"。

第二个误解更顽固：我以为聚类就是分类换了个说法。后来才想通两者的顺序完全相反。分类是先有抽屉，再往里放东西——抽屉的名字（违规 / 不违规）是人定义的，模型学的是"该怎么放"；聚类是先看东西自己怎么抱团，抱完了再给每团起名字——名字是事后由人贴上去的，而且这次叫"民生诉求"，换个人看可能叫"市政投诉"。这也是无监督结果更依赖解释的原因。

第三个收获是关于"怎么证明它好"。我原以为评估就是算准确率，看了 scikit-learn 的聚类文档才发现不行：聚类结果的标签编号本身没有意义——把第一类和第二类的编号对调，聚类完全没变，但按编号算准确率就会全错。所以文档强调评估指标不该看标签的绝对值，而该看"这种分法是否与某个真实分组相似"。这解释了我之前的困惑：为什么无监督的评估要么得有真值（有真值时用调整兰德指数这类指标，随机分组大约得 0 分），要么只能靠模型自身（如轮廓系数）——而后者只是一个参考，最终仍需要人来看这批分组是否有意义。

3.2 核心机制与组成

① 分界线：有没有标签——四种学习方式放在一起看最清楚：

方式数据情况模型在学什么典型任务
监督学习
Supervised		全部样本都有标签（真实基准，ground truth）从特征到标签的映射关系分类、回归
无监督学习
Unsupervised		只有样本，没有任何标签数据内部的结构、相似性与分组聚类、降维、异常检测
半监督学习
Semi-supervised		少量有标签 + 大量无标签先用少量答案打底，再用无标签数据扩展标注成本高的分类任务
自监督学习
Self-supervised		全部无人工标签让模型自己从数据中造出监督信号（伪标签）预训练语言模型、视觉表征学习

说明：IBM 在讲监督学习时把半监督与自监督列为相邻的学习方式；自监督常被描述为连接监督与无监督的桥梁，也是当前大模型预训练的基础做法。

② 监督学习的两大任务：分类与回归——判断标准是输出长什么样：

维度分类 / Classification回归 / Regression
输出类型离散的类别（是/否、违规/不违规、A/B/C）连续的数值（金额、时长、气温、阅读量）
在问什么"它属于哪一类？""它会是多少？"
新闻场景判断一条读者留言是否包含广告导流预测一篇稿件上线 24 小时内的阅读量
常用算法逻辑回归、支持向量机、决策树、朴素贝叶斯、K 近邻、随机森林线性回归、多项式回归、回归树、随机森林回归
评估关注点两类错误要分开看（漏判 / 误判的代价不同）预测值与真实值的平均偏差有多大

说明：IBM 与 scikit-learn 的分类方式一致——回归预测连续值、分类预测离散类别；不少算法稍作调整后两者都能用。

③ 常见监督学习算法速览——先记住"它擅长什么"，不必背公式：

算法一句话理解适合什么
线性回归 / Linear Regression用一条直线（或平面）去拟合变量之间的关系趋势平缓的数值预测
逻辑回归 / Logistic Regression名字里有"回归"，实际用来做二分类是 / 否型判断，如垃圾邮件识别
决策树 / Decision Tree一连串"如果……就……"的判断分支需要能读懂判断路径的场景
支持向量机 / SVM在两类数据之间画一条尽可能"留有余地"的分界线样本不多、维度较高的分类
K 近邻 / KNN看离它最近的 K 个邻居多数属于哪类小规模分类与推荐，数据大时变慢
朴素贝叶斯 / Naive Bayes按词出现的概率推断类别文本分类、情感判断
随机森林 / Random Forest把很多棵不相关的决策树投票汇总分类与回归通用，效果较稳

说明：以上算法名与用途依据 IBM 监督学习条目的算法清单；scikit-learn 文档中对应章节为 Linear Models（含 Logistic regression）、Support Vector Machines、Decision Trees、Naive Bayes、Nearest Neighbors、Ensembles。

④ 常见无监督方法速览——两条主线是"分组"与"压缩"：

方法做什么新闻场景例子
K-means 聚类预先指定分成 K 组，反复调整每组中心，让组内差异尽量小把上千条读者留言分成若干话题群
层次聚类 / Hierarchical Clustering像建族谱一样逐步合并或拆分，能得到不同粒度的分组看报道主题的粗细层级关系
DBSCAN按"密度"找成团的点，能识别形状不规则的群并标出离群点从海量账号中发现异常的传播行为
降维：PCA / t-SNE把高维数据压到两三维，便于观察与可视化把上千个特征的话题分布画成一张可读的散点图
主题模型（如 LDA）从大量文档中归纳出若干主题及其词分布快速把握一批稿件的主题构成

说明：scikit-learn 的无监督学习章节把聚类（K-means、层次聚类、DBSCAN 等）与降维/矩阵分解（PCA、NMF、LDA 等）分列；K-means 需预先指定簇数并最小化簇内平方和（inertia），且结果可能停留在局部最优，常用 k-means++ 初始化改善。

⑤ 无监督怎么"评卷"——有没有真值是两条不同的路：

情形可用指标怎么读结果
手里有真实分组（真值标签）调整兰德指数 ARI、调整互信息 AMI、同质性 / 完整性 / V-measure、Fowlkes-Mallows看与真实分组的吻合程度；随机分组时 ARI 与 AMI 大约为 0，因此可作基线
没有真实分组（绝大多数情况）轮廓系数（Silhouette）、Calinski-Harabasz 指数轮廓系数从 -1（分错）到 +1（又紧又分得开），接近 0 说明各组有重叠；只是参考，仍需人工判断分组是否有意义

说明：scikit-learn 提示，聚类评估不应依据簇编号的绝对值；同时提醒轮廓系数对凸形簇更友好，对 DBSCAN 这类基于密度的结果未必公平。

⑥ 标注太贵怎么办：半监督与自监督

半监督（Semi-supervised）：少量人工标签打底 + 大量无标签数据一起用 → 缓解"标注贵"
自监督（Self-supervised）：不给人工标签，让模型自己从数据里造"伪标签"（如把句子挖空让模型补）→ 支撑大模型预训练

3.3 关键术语（中英对照）

  • 标签 / Label：样本对应的正确答案，是监督学习成立的前提。
  • 特征 / Feature：描述样本的可计算属性，是模型实际接收的输入。
  • 分类 / Classification：预测离散类别的监督任务。
  • 回归 / Regression：预测连续数值的监督任务。
  • 聚类 / Clustering：把相似的样本分到同一组的无监督方法，分完的组需要人来命名解释。
  • 降维 / Dimensionality Reduction：在尽量保留信息的前提下减少特征数量，便于计算与可视化。
  • 真实基准 / Ground Truth：经人工标注或实测确认的参考答案，用于训练、验证与评估。
  • 半监督学习 / Semi-supervised Learning：少量标签数据加大量无标签数据一起训练。
  • 自监督学习 / Self-supervised Learning：模型自己生成监督信号，无需人工逐条标注。

4. 应用场景示例

场景同一批读者留言，两种思路分别能问出什么

假设编辑部拿到某热点事件下的一万条留言。监督与无监督在这里不是谁更高级，而是回答两个不同的问题：前者回答"这条要不要处理"，后者回答"大家在聊什么"。

  1. 先明确要回答的问题：要"按规则逐条判定"（监督，需要标签），还是要"看清话题分布"（无监督，不需要标签）。两个都想要，就分成两条独立的流水线，不要混在一次训练里。
  2. 无监督路线：聚类找话题群。把留言转成可计算的表示，选定聚类方法（如 K-means）与簇数，跑出若干群，再由记者逐群阅读、给每群起名。注意簇数需要试几组、对比"分得紧不紧"，而不是拍一个数字就完事。
  3. 给聚类结果做人工判读：把每群的代表性留言抽出来核对，确认这一群是不是一个真实话题，有没有把两种不相干的内容混在一起。若混在一起，可能是簇数或数据表示需要调整。
  4. 监督路线：训练违规初筛。从历史留言中抽取样本，按事先写好的判定说明标注"违规 / 不违规"，形成真实基准；切成训练集、验证集、测试集后训练与评估。
  5. 分类任务要分开看结果：把所有漏放和误伤的案例各抽一批人工复盘——只看总体准确率会掩盖"某一类表达被系统性误判"的问题。
  6. 两条线互相校对：如果某个聚类出来的话题群里违规比例异常高，值得回头检查标注口径是不是把"讨论某话题"误当成了"违规"。
新闻视角：对记者来说，聚类最大的风险是"看起来像结论"：一堆分组配上漂亮的名字，读者会以为这就是事实，但分组边界其实是算法参数与人为命名的产物——换一次簇数，分组就变了。稳妥的做法是：公开说明数据范围、所用的方法与参数、由谁命名，并标注这是探索性发现而非定论。相对地，监督学习的风险在标签口径：如果判定说明写得不细，不同标注员对同一条留言给出不同答案，模型学到的就是"模糊的平均口径"，最后既不可复核也不可解释。

5. 概念辨析与使用边界

对比维度概念 A易混淆对象 B
分类 vs 回归输出是离散类别，问"属于哪一类"；评价时漏判与误判的代价要分开算输出是连续数值，问"会是多少"；评价看预测值与真实值的平均偏差
聚类 vs 分类无监督：先看数据怎么抱团，事后由人给每组命名，组数可调、结果依参数而变监督：事先由人定义类别并用标签教会模型，类别含义固定、可复用
监督 vs 无监督有外部标准答案可对，因此能算"对了多少"，评估相对客观没有标准答案，只能从数据内部找结构，评估依赖内部指标加人工判读
半监督 vs 自监督半监督：少量人工标签 + 大量无标签数据，标签不足但仍需要一些自监督：完全不要人工标签，靠"从数据本身造任务"获得监督信号
降维 vs 特征选择把原有特征重新组合压缩成更少的新维度（如 PCA），信息有变换直接丢掉不重要的原始特征、保留其余原样，更容易解释

使用边界提醒：无监督学习的输出不能当作既定事实来引用。聚类结果对参数（如簇数）、距离定义与数据预处理都很敏感，同一批数据换一组设置可能给出不同分组；"没有标签"也意味着无法自动发现偏差——如果数据本身只覆盖了某一类声音，聚类只会把这种片面的样本结构忠实地呈现出来。用于报道时，应说明方法与局限，并把分组结论与人（被访者、专家、当事人）的核对结合起来。

6. 自测问题

Q1：标签和特征分别是什么？举一个"读者留言分类"的例子说明。

参考答案：特征是模型实际接收的输入，是描述样本的可计算属性；标签是我们希望模型输出的正确答案。在读者留言分类里，特征可以是留言的字数、出现的词、是否含链接等；标签则是人工判定的"违规 / 不违规"。监督学习学的正是从特征到标签的映射关系，所以没有标签就没法做监督学习。

Q2：下面哪个是分类、哪个是回归？① 判断一篇稿件是否属于突发报道；② 预测一篇稿件的阅读量。

参考答案：① 是分类，因为输出是离散类别（是 / 否）；② 是回归，因为输出是连续数值。判断依据是"输出的形态"，不是任务听起来难不难。注意逻辑回归虽然名字带"回归"，实际常用于二分类——看名字容易被误导。

Q3：为什么不能简单地用"准确率"来评价聚类结果？

参考答案：因为聚类给出的簇编号本身没有意义——把第 1 簇和第 2 簇的编号互换，分组其实完全没变，但按编号逐条比对就会全部算错。scikit-learn 因此强调：评估指标不应看标签的绝对值，而应看"这种分法是否与某个真实分组相似"。有真值标签时可用调整兰德指数、调整互信息等指标（随机分组时它们接近 0，便于做基线）；没有真值时只能依赖轮廓系数、Calinski-Harabasz 这类内部指标，而它们只是参考，仍需人工判断分组是否有意义。

Q4：编辑部只有 500 条人工标注过的评论，另有 20 万条未标注评论。可以怎么做？

参考答案：这是典型的半监督学习场景：用 500 条带标签数据打底，再让大量未标注数据参与训练，缓解"标注贵、标注慢"的问题。但要提醒两点：一是未标注数据里的噪声与隐性偏差会影响结果，需要先检查数据质量；二是这 500 条标签本身必须有统一口径，否则偏差会被放大。如果完全不做任何人工标注，则属于自监督的思路——让模型自己从数据里造监督信号，通常用于大规模预训练而非直接产出可用的审核模型。
